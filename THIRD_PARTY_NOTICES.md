# Third-Party Notices

Engineering Calculator v1.0.0 contains no bundled third-party library code.

The application uses browser-native APIs, system fonts, inline SVG, and formulas implemented in the application source. `dependencies.json` is intentionally empty.

GitHub Actions or repository tooling, when used, remain subject to the terms of their respective projects.

When a future version adds a package to `dependencies.json`, record its exact version, license, homepage, required notices, and all embedded support assets here before release.
