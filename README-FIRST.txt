Engineering Calculator — First Steps
====================================

1. Read README.md or README.ja.md for features and usage.
2. Edit application source in src/index.template.html; do not edit dist/index.html directly.
3. Keep APP_SPEC.md, CHANGELOG.md, README files, and docs/FORMULA_REFERENCES.md in sync with user-visible behavior.
4. Run build-standalone.bat on Windows before release.
5. Run scripts/check-repository.ps1 and review dist/build-size-report.json.
6. Open both dist/index.html and dist/index.self-extract.html directly and test desktop, smartphone, keyboard-only, Japanese/English, and network-disabled operation.
7. Engineering helper presets are conveniences only; confirm applicable drawings, standards, material data, and manufacturer information for final design work.
